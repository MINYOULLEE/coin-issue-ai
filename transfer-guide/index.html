초보자용 입금 가이드

원화로 코인 사고
해외거래소로 보내기

복잡한 설명 없이, 화면을 보면서 순서대로 따라가면 됩니다.

이미 BingX 또는 Bitget 계정이 있고 KYC 인증까지 끝났다면 3번부터 시작하세요.

내가 사용하는 국내거래소 선택

업비트 사용자 업비트 → BingX

업비트에서 XRP를 구매해 BingX로 전송합니다.

BingX 가입하기 업비트 열기
빗썸 사용자 빗썸 → Bitget

빗썸에서 XRP를 구매해 Bitget으로 전송합니다.

Bitget 가입하기 빗썸 열기
초대코드  BA53PFV9

1. 해외거래소 가입

1

업비트 사용자 → BingX 가입

아래 버튼으로 가입하고 이메일 또는 휴대폰 인증까지 완료합니다.

BingX 가입 링크
1

빗썸 사용자 → Bitget 가입

회원가입할 때 초대코드 BA53PFV9를 확인합니다.

Bitget 가입 페이지

2. KYC 본인인증

2

신분증 + 얼굴 인증 완료

BingX 또는 Bitget 로그인 → 프로필 → Identity Verification에서 본인인증을 진행합니다.

가입만 하고 끝내지 말고, 상태가 Verified / 인증 완료인지 확인하세요.

3. 해외거래소에서 XRP 입금주소 확인

3

Assets → Deposit → XRP

BingX 또는 Bitget에서 XRP 입금을 선택하고 아래 3가지를 확인합니다.

① XRP Address   ② Network   ③ Destination Tag / Memo

4. 국내거래소에서 XRP 구매

4

원화 입금 → XRP/KRW 매수

업비트 또는 빗썸에 원화를 입금하고 XRP/KRW에서 원하는 금액만큼 XRP를 구매합니다.

업비트 열기 빗썸 열기

5. XRP 출금

5

받는 거래소 선택

업비트는 BingX, 빗썸은 Bitget을 선택합니다.

5

Address + Tag 입력

해외거래소에서 복사한 XRP Address와 Destination Tag / Memo를 정확히 붙여넣습니다.

직접 타이핑하지 말고 반드시 복사 → 붙여넣기를 권장합니다.

6. 처음이면 소액 테스트

6

작은 금액 먼저 보내기

처음부터 전액을 보내지 말고 소액 XRP를 먼저 전송합니다.

소액 전송 → 해외거래소 입금 확인 → 정상 확인 후 나머지 전송

7. XRP를 USDT로 변경

7

XRP/USDT에서 XRP 매도

해외거래소에 XRP가 정상 입금되면 XRP/USDT 거래에서 XRP를 매도합니다.

XRP → USDT 변경이 완료되면 해외거래소에서 사용할 USDT 준비가 끝납니다.
⚠️ 출금 전 꼭 확인하세요
  • XRP를 보낼 때는 반드시 XRP 입금주소를 사용하세요.
  • 보내는 쪽과 받는 쪽의 네트워크가 같은지 확인하세요.
  • XRP는 Destination Tag / Memo가 표시되면 반드시 함께 입력하세요.
  • 본인 명의 국내거래소 → 본인 명의 해외거래소 전송을 기준으로 합니다.
  • 거래소 정책은 변경될 수 있으므로 실제 출금 화면에서 대상 거래소가 정상 선택되는지 마지막으로 확인하세요.
딱 이것만 기억하세요

빗썸 → XRP → Bitget → USDT
