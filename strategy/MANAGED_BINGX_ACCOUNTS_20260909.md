# 타인 BingX 계정 확장 틀 — 2026-09-09

사용자는 앞으로 타인의 BingX API 키와 시크릿을 받아 이름·시작금액을 등록하고, 계정별로 A 또는 B 전략을 선택 배정하려 한다. 현재 실제 연결 대상과 키는 없으므로 이번 작업은 안전한 빈 구조와 조회 UI만 배포한다.

## 분리 원칙

- 기존 A와 B 계정·자격증명·신호·주문·장부·스위치는 변경하지 않는다.
- 타인 계정은 `managed_bingx_accounts`, 거래는 `managed_bingx_trades`에만 보관한다.
- API 키와 시크릿 원문은 일반 테이블에 저장하지 않는다. 계정 테이블에는 Supabase Vault의 불투명한 secret UUID 참조만 허용한다.
- 각 계정은 `assigned_plan` A 또는 B 하나를 명시적으로 가진다. 플랜을 추론하거나 기존 A/B 자격증명으로 대체하지 않는다.
- 새 계정은 `draft`, `live_enabled=false`, `alerts_enabled=false`가 기본이다. 실제 키 연결, 읽기 전용 계좌 확인, 플랜/레버리지/헤지·격리/권한 사전점검, 사용자 승인 전에는 주문을 허용하지 않는다.
- 타인 계정의 자동 진입·청산 알림은 계정별 `alerts_enabled=true`로 직접 변경하기 전까지 발송하지 않는다.

## 제공 화면과 Telegram

- 대시보드 `타인 API 연동`은 별도 M 세션으로 잠겨 있으며 A/B 세션과 상호 사용할 수 없다.
- 목록에는 이름, 배정 플랜, 시작금액, 현재 Equity, 연결 상태만 표시한다.
- 거래내역은 계정 카드를 실제로 펼칠 때만 지연 조회하며 자격증명·주문 식별자·제어 필드를 반환하지 않는다.
- Telegram 메뉴의 `타인 API 연동`은 등록된 계정의 이름·플랜·시작금·현재 Equity·알림 상태를 보여준다. 계정별 인라인 버튼을 눌렀을 때만 최근 거래를 조회한다.
