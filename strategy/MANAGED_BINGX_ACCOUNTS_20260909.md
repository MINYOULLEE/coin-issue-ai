# 타인 BingX 계정 확장 틀 — 2026-09-09

사용자는 앞으로 타인의 BingX API 키와 시크릿을 받아 이름·시작금액을 등록하고, 계정별로 A 또는 B 전략을 선택 배정하려 한다. 현재 실제 연결 대상과 키는 없지만, 소유자 화면에서 키 입력과 읽기 전용 BingX 연결 점검 및 Vault 저장까지 수행할 수 있다.

## 분리 원칙

- 기존 A와 B 계정·자격증명·신호·주문·장부·스위치는 변경하지 않는다.
- 타인 계정은 `managed_bingx_accounts`, 거래는 `managed_bingx_trades`에만 보관한다.
- API 키와 시크릿 원문은 일반 테이블에 저장하지 않는다. 계정 테이블에는 Supabase Vault의 불투명한 secret UUID 참조만 허용한다.
- 각 계정은 `assigned_plan` A 또는 B 하나를 명시적으로 가진다. 플랜을 추론하거나 기존 A/B 자격증명으로 대체하지 않는다.
- 새 계정은 API 인증·USDT 선물 Equity·헤지 모드·기존 포지션 0건을 모두 확인한 뒤에만 `connected`로 저장한다. `live_enabled=false`, `alerts_enabled=false`가 기본이며, 계정별 실행기·플랜별 레버리지/격리·권한 사전점검과 사용자 승인 전에는 주문을 허용하지 않는다.
- API 키와 시크릿은 HTTPS 요청 본문으로 한 번만 전달되고, 서버에서 Supabase Vault에 직접 암호화 저장한다. 일반 테이블·응답·로그에는 원문을 쓰지 않는다.
- 타인 계정의 자동 진입·청산 알림은 계정별 `alerts_enabled=true`로 직접 변경하기 전까지 발송하지 않는다.

## 제공 화면과 Telegram

- 대시보드 `타인 API 연동`은 별도 M 세션으로 잠겨 있으며 A/B 세션과 상호 사용할 수 없다.
- 목록에는 이름, 배정 플랜, 시작금액, 현재 Equity, 연결 상태만 표시한다.
- 거래내역은 계정 카드를 실제로 펼칠 때만 지연 조회하며 자격증명·주문 식별자·제어 필드를 반환하지 않는다.
- Telegram 메뉴의 `타인 API 연동`은 등록된 계정의 이름·플랜·시작금·현재 Equity·알림 상태를 보여준다. 계정별 인라인 버튼을 눌렀을 때만 최근 거래를 조회한다.

## 입력 화면

- 필수 입력: 이름, A 또는 B, 시작금액(USDT), BingX API Key, Secret Key.
- `저장하고 연결 점검`은 읽기 전용 호출만 수행한다. 기존 포지션이 있거나 헤지 모드가 아니면 저장하지 않는다.
- 연결 성공은 자동주문 활성화와 다르다. 계정별 주문 예약·중복방지·장부를 갖춘 실행기가 배포되기 전까지 `live_enabled`를 켜지 않는다.

## 현재 상태

- 등록 후 `연결 다시 확인`은 Vault 원문을 화면에 노출하지 않고 서버 내부에서 BingX 인증·USDT 선물 Equity·가용담보·헤지 모드·포지션 수를 재검증하며 마지막 확인시각과 오류를 저장한다.
- 시작금액은 소유자 M 세션에서만 수정할 수 있다. API 키·배정 플랜·자동매매 상태는 함께 변경하지 않는다.
- `연동 취소`는 `live_enabled=false`, 진행 중 거래 0건, 보존할 거래 이력 0건일 때만 계정과 Vault 키를 같은 트랜잭션에서 삭제한다.
- A플랜 계정은 전용 `managed-account-executor`가 A `answer_mdd30` 신호를 구독한다. Vault 키, 주문, 중복방지 키와 장부는 계정 ID로 분리하며 기존 A 계정 자격증명으로 대체하지 않는다.
- LIVE를 켤 때마다 API 인증·USDT 선물 Equity·헤지 모드·기존 포지션 0건을 다시 검사한다. 활성화 이전의 오래된 신호는 추격하지 않고 `live_enabled_at` 이후 확정된 신호만 진입한다.
- 주문은 Equity 비례 A 노출, 격리 3배, 총 명목노출 2.24배, 담보 80%/종목 60% 상한을 적용하고 BingX 주문 테스트 후 전송한다. 진입 직후 15% 비상 손절을 붙이며 손절 부착 실패 시 안전 시장가 청산을 보낸다.
- 현재 타인계정 실거래 실행은 A플랜만 승인 범위다. B를 선택한 계정은 별도 B 전용 실행기가 검증·배포되기 전 LIVE 활성화를 거부한다.
