# B Stage112 자동 위험기준·만료 신호 실행 보수 — 2026-09-24

## 사용자 지시

실거래를 연구 기준과 대조하면서 `1=완전자동`, `2=사용자 개입`을 분리해 분석한 결과를 바탕으로 실행 오류 수정을 진행한다. A/B 연구 신호와 채택 수치는 변경하지 않는다.

## 확인된 문제

- B Stage112 낙폭 보호가 B 자동 원장이 아니라 수동 거래와 입출금이 포함된 거래소 계좌 전체 Equity를 사용했다.
- 사용자의 `2` 거래 때문에 자동전략이 고점 대비 25% 낙폭으로 오인되어 168시간 신규진입 정지에 들어갔다.
- 실행기가 위험정지에서 먼저 반환하여 진입기한이 지난 미체결 신호가 `active`로 누적됐다.

## 보수 기준

- 주문 수량과 가용담보 계산은 계속 실제 BingX balance/equity/free margin을 사용한다.
- Stage112 낙폭 보호만 `$650 + control_marker=1 자동 확정손익 + 자동 오픈수량 평가손익`으로 계산한다.
- `control_marker=2` 거래와 계좌 입출금은 자동전략 낙폭에 포함하지 않는다.
- 위험정지·OFF·TEST 여부를 반환하기 전에 진입기한이 지난 미체결 신호를 `expired`로 정리한다.
- 기존 A/B 전략 ID, 신호 조건, 레버리지, 보유시간, 담보 배분, 총노출 상한은 변경하지 않는다.

## 운영 주의

이 보수는 과거 연구 성과를 새로 주장하지 않는다. 배포 후 최초 자연 신호·체결·청산을 `1`로 확인해야 실제 검증 상태가 진행된다.
