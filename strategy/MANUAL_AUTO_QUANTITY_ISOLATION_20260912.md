# 수동·자동 포지션 수량 분리 — 2026-09-12

사용자는 기존 A, 기존 B 및 모든 타인 API 연결 계정에 공통으로 수동매매와 자동매매 수량을 분리하는 안전 보완을 승인했다.

## 불변 원칙

- 자동매매는 자체 장부에 기록된 체결 수량만 소유 수량으로 간주한다.
- BingX 헤지 모드에서도 동일 종목·동일 방향의 수동·자동 주문은 거래소 포지션 하나로 합쳐지므로, 수동 수량이 먼저 존재하면 해당 자동 신규진입을 거부한다.
- 수동 포지션은 자동 거래기록, 손절, 익절 및 전략 청산 대상으로 편입하지 않는다.
- 다른 종목 또는 반대 방향의 수동 포지션은 건드리지 않지만 실제 Equity·가용담보·총 명목노출 계산에는 포함한다.
- 거래소 수량이 자동 장부보다 크면 전체수량 청산을 금지한다. A는 보호주문 소유권을 과거 장부에서 확정할 수 없어 자동 청산을 차단하며, B는 저장된 수동 잔량을 남기고 자동 소유수량만 청산한다.
- 타인 계정은 저장된 자동 손절 주문 ID만 취소하고 자동 체결수량 이하만 청산한다.
- 수량 불일치는 신규진입을 허용하는 근거가 아니며, 오류를 숨기거나 수동 물량을 자동 장부에 맞춰 추정하지 않는다.

## 적용 파일

- A: `supabase/functions/bingx-order-execute/index.ts`
- B: `supabase/functions/_shared/plan_b_live_cycle.mjs`
- 타인 A: `supabase/functions/managed-account-executor/index.ts`
- B 재시도 중 수동 잔량 보존: `plan_b_execution_intents.manual_remainder_qty`

같은 종목·같은 방향을 수동과 자동으로 동시에 운용해야 한다면 BingX 계정을 별도로 분리하는 것이 유일하게 완전한 거래소 수준 격리다.
