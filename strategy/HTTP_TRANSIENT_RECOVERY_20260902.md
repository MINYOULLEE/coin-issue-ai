기존 알림기는 전송 계층의 일회성 장애도 즉시 확정 오류로 전송했다. 보수 후 기준은 다음과 같다.

- JSON `ok=false`, 주문·신호·청산 결과 오류 등 애플리케이션/매매 오류는 계속 즉시 알린다.
- DNS, timeout, 비 JSON 5xx만 최대 3분 동안 `pending_transport_errors`에 보류한다.
- 오류 시각 이후 A 수집기 heartbeat와 B signals/execute/close가 모두 `ok=true`로 새로 갱신되면 복구가 입증된 일회성 전송 장애로 폐기한다.
- 3분 안에 위 의미 기반 복구가 확인되지 않으면 기존 시스템 오류 알림을 보낸다.
- A/B ON/OFF, 신호 조건, 주문, 담보, 레버리지는 변경하지 않는다.
