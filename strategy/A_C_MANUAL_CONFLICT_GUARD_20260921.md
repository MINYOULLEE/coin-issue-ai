# A + C 수동 방향 충돌 방지 — 2026-09-21 승인

## 사용자 승인

같은 종목에 사용자가 수동 LONG을 보유하면 A 자동 SHORT 신호를 실행하지 않고, 수동 SHORT을 보유하면 A 자동 LONG 신호를 실행하지 않는다. 이미 양방향 충돌이 존재하면 수동수량은 유지하고 충돌하는 A 자동수량만 청산한다.

## 실행 기준

- 신규 주문 직전에 BingX 실제 포지션을 다시 읽어 반대방향 보유량이 있으면 A 자동 진입을 차단한다.
- 매 수집 주기마다 거래소 실제 수량에서 자동 장부 수량을 차감해 수동 반대방향 수량을 판별한다.
- 수동 반대방향 수량이 확인되면 해당 종목의 A 자동수량만 청산한다.
- 같은 방향에 수동수량이 합쳐져 자동수량만 안전하게 분리 청산할 수 없으면 기존 보호 규칙대로 청산하지 않고 오류를 남긴다.
- 수동수량은 C가 청산·축소·리사이즈하지 않는다.
- B 플랜과 타인계정 자격증명·장부·주문에는 이 규칙을 혼합하지 않는다.

## 연구 수치 영향

이 규칙은 과거 데이터에서 생성되는 A 신호를 바꾸지 않고 사용자의 실시간 수동 개입이 있을 때만 작동한다. 따라서 기존 5년·7년 자동전략 재생 수치를 새 성과로 다시 주장하지 않으며, 운영 실행 안전장치로만 기록한다.
