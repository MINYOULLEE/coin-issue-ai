# Stage25 — 청산 확인 후 B 대기·재진입·만료까지 반영

2026-08-31. **연구용 시뮬레이션 결과이며 운영 구현·배포·실주문 검증이 아니다.**

## 무엇을 검증했나

기존 B + ALGO/ETH/VET 반전 보조 조합은 유지했다. 보조 80건 모두의 청산이 0/1/3/5/10분 지연된다고 가정했다. 보조 포지션 종료가 확인될 때까지 B 진입을 대기시킨다. 체결과 확인을 구분해 청산 체결 1분 지연 + 확인 응답 4분 추가 지연도 시험했다.

1. 보조가 아직 열려 있으면 B 진입 대기.
2. 체결 후에도 확인이 미완료면 예약 담보 유지.
3. 확인 후 B 원래 신호 확정 시각으로부터 **5분 미만**일 때만 재진입 가능.
4. 재진입 가격이 원래 신호봉 종가보다 방향상 0.35% 넘게 불리하면 폐기.
5. 5분 이상이면 신호 폐기. B 종료 예정시각은 지연 때문에 연장하지 않음.

매번 포지션·현금·예약 담보 상태를 시간순으로 업데이트하고 그 상태에서 배분했다. 미래 B 신호로 보조 진입을 새로 선별하지 않았다. B 거래가 사라져도 대체 보조 신호를 추가하지 않았다.

## 자료와 계산 기준

- $100 시작, 기존 5년 구간. 신호당 보조 희망 담보 90%, 3배, 가용 담보 내 비례 감액, equity 5% 버퍼, 수량 고정.
- 수수료 편도 0.05%, 슬리피지 편도 0.02%, 펀딩 8시간당 0.01% 지급 가정.
- 보조 진입 지연은 0으로 고정; **이번은 청산/확인 지연만** 변경했다. Stage24 진입 지연과 동시에 적용한 결과가 아니다.
- Stage24 보조 80건 분봉에 충돌한 BCH·UNI의 공개 1분봉 두 구간을 추가했다. Binance 현물 자료이며 BingX 선물 호가/체결 기록이 아니다.
- 새 시간순 계산기가 지연 0의 최종금과 시간별 MDD를 기존 동결 조합 결과와 동일하게 재현했다.
- 원래 시간봉 데이터의 공백에서는 이전 공통 유효 봉을 사용하여 동결 기준의 평가를 재현했다. 공백의 실제 가격 경로를 복원한 것은 아니다.
- 지연 B의 첫 시간 펀딩은 기존 1시간분을 유지했고, 늦게 청산된 보조에는 지연 시간만큼 추가 펀딩을 안분 부과했다. 실제 펀딩 정산 시각을 재현하지는 않았다.
