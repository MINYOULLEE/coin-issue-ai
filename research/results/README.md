# 연구 결과 색인

연구 결과는 판정에 따라 아래 두 폴더에 기록한다. 기존 산출물은 원위치를
유지하고, 이 색인에서 연결해 중복 연구를 피한다.

- [성공 후보](success/README.md): 채택 기준을 통과했거나 다음 단계 검증 가치가 있는 결과
- [실패 기록](failure/README.md): 기준 미달·과적합·독립검증 실패 결과

## 공통 기록 항목

- 연구 ID와 날짜
- 데이터 기간·시간봉·대상
- 진입 및 청산 규칙
- 레버리지·수수료 가정
- 3분할 교차검증 결과
- 거래횟수·승률
- $100 시작 최종금액·5년 복리 수익률
- 최대낙폭(MDD)
- 성공·실패 사유와 다음 검증 항목
