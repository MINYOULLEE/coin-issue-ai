거래소 이용방법,
처음부터 쉽게

국내 거래소에서 코인을 구매하고 해외 거래소로 안전하게 보내는 과정을 한눈에 정리했습니다. 마지막에는 BingX API 연결 방법까지 이어집니다.

⚠️ 거래소 화면의 코인·네트워크·Tag/Memo는 수시로 바뀔 수 있습니다. 실제 출금 직전 양쪽 화면의 정보를 반드시 다시 비교하고, 처음에는 소액 테스트를 권장합니다.
업비트 → BingX빗썸 → BitgetBingX API 발급최종 체크리스트

01 · 업비트 → BingX

업비트에서 XRP를 구매해 BingX로 전송한 뒤 USDT로 바꾸는 흐름입니다.

1
업비트에 원화 입금
입출금 → 원화 → 입금에서 본인 명의 계좌로 입금합니다.
2
XRP 구매
XRP/KRW 마켓에서 전송할 금액만큼 매수합니다.
3
BingX 입금 화면 열기
Assets → Deposit → XRP를 선택하고 네트워크를 확인합니다.
4
Address와 Tag 복사
XRP는 보통 입금주소와 Destination Tag를 함께 요구합니다.
5
업비트에서 출금
입출금 → XRP → 출금에서 받는 거래소를 BingX로 선택하고 주소·Tag를 입력합니다.
6
소액 테스트 후 입금 확인
BingX 잔고에 XRP가 들어오면 XRP/USDT에서 USDT로 교환합니다.
업비트 원화→XRP→BingX XRP→BingX USDT

02 · 빗썸 → Bitget

빗썸을 이용한다면 같은 원리로 XRP를 전송합니다. Bitget의 XRP Tag를 빠뜨리지 않는 것이 핵심입니다.

1
빗썸에 원화 입금
입출금 → 원화 → 입금에서 본인 명의 계좌를 사용합니다.
2
XRP 구매
XRP/KRW 마켓에서 원하는 금액만큼 매수합니다.
3
Bitget XRP 입금주소 확인
Assets → Deposit → XRP에서 Address, Network, Tag/Memo를 확인합니다.
4
주소와 Tag 입력
빗썸 출금 화면에서 받는 거래소 Bitget을 선택하고 두 값을 각각 붙여 넣습니다.
5
본인확인·트래블룰 진행
출금 화면의 거래소 선택, 수취인 정보, 추가 보안인증을 완료합니다.
6
입금 확인 후 USDT 교환
Bitget XRP 잔고를 확인한 뒤 XRP/USDT에서 매도합니다.
빗썸 원화→XRP→Bitget XRP→Bitget USDT

03 · BingX API 키 받기

API는 자동매매 프로그램이 거래소 계좌를 조회하거나 주문할 때 사용하는 연결 열쇠입니다. 키 자체를 웹페이지·채팅·GitHub에 올리면 안 됩니다.

1
BingX 로그인 → API 관리
프로필 또는 계정 보안 메뉴에서 API Management를 엽니다.
2
Create API Key
새 API 키를 만들고 용도를 알아보기 쉬운 이름으로 지정합니다.
3
권한 최소 설정
잔고·포지션 조회와 필요한 거래 권한만 켭니다. 출금 권한은 절대 켜지 않습니다.
4
IP 제한 설정
가능하면 자동매매 서버의 고정 IP만 허용합니다. 전체 IP 허용은 피합니다.
5
Secret Key 즉시 보관
생성 직후 한 번만 표시될 수 있으므로 비밀번호 관리자 또는 서버 비밀변수에 저장합니다.
6
연결 테스트
키와 시크릿을 코드에 직접 쓰지 말고 환경변수로 등록한 뒤, 먼저 잔고 조회만 테스트합니다.
✓ 권장읽기·잔고·포지션 조회
필요한 경우에만 선물 거래
✕ 금지출금 권한
공개 저장소·스크린샷·메신저 공유
