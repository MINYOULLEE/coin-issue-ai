거래소 이용방법,
처음부터 쉽게

국내 거래소에서 코인을 구매하고 해외 거래소로 안전하게 보내는 과정을 한눈에 정리했습니다. 마지막에는 BingX API 연결 방법까지 이어집니다.

⚠️ 거래소 화면의 코인·네트워크 정보는 수시로 바뀔 수 있습니다. 실제 출금 직전 양쪽 화면을 반드시 다시 비교하고, 처음에는 소액 테스트를 권장합니다.

00 · 가입 & KYC 먼저 하기

코인을 보내기 전에 네 거래소 모두 계정을 만들고 본인인증을 완료해야 합니다. 가입 이메일과 휴대폰은 본인이 관리하는 정보로 사용하세요.

국내 거래소

업비트 · 빗썸
1
앱 또는 공식 웹사이트 접속
검색 광고보다 공식 앱스토어·공식 도메인을 이용합니다.
2
이메일·휴대폰 가입
강한 비밀번호와 2단계 인증을 설정합니다.
3
KYC 본인인증
신분증, 본인 명의 휴대폰, 필요 시 계좌 인증을 진행합니다.
4
입출금 가능 상태 확인
인증 단계와 원화 입출금 제한이 해제됐는지 확인합니다.

해외 거래소

BingX · Bitget
1
공식 사이트·앱에서 가입
이메일 또는 휴대폰으로 가입하고 추천코드는 선택사항으로 확인합니다.
2
Identity Verification / KYC
여권·주민등록증 등 허용 신분증과 셀피 인증을 진행합니다.
3
2FA와 출금 보안 설정
Authenticator 앱, 출금 비밀번호·주소록 보안 등 제공 기능을 켭니다.
4
입금 화면이 열리는지 확인
TRX 입금 지원 여부와 TRON(TRX) 네트워크를 먼저 확인합니다.
🔐 KYC가 완료되지 않으면 입출금·거래 한도 또는 기능이 제한될 수 있습니다. 이름·생년월일은 국내외 거래소 계정에서 일치해야 하며, 허위 정보나 타인 명의 계정은 사용하지 마세요.

01 · 업비트 → BingX

업비트에서 TRX를 구매해 BingX로 전송한 뒤 USDT로 바꾸는 흐름입니다.

1
업비트에 원화 입금
입출금 → 원화 → 입금에서 본인 명의 계좌로 입금합니다.
2
TRX 구매
TRX/KRW 마켓에서 전송할 금액만큼 매수합니다.
3
BingX 입금 화면 열기
Assets → Deposit → TRX를 선택하고 네트워크가 TRON(TRX)인지 확인합니다.
4
입금주소 복사
TRX는 Destination Tag를 쓰는 방식이 일반적이지 않습니다. 그래도 화면에 추가 메모가 표시되면 반드시 확인합니다.
5
업비트에서 출금
입출금 → TRX → 출금에서 받는 거래소를 BingX로 선택하고 주소·네트워크를 입력합니다.
6
소액 테스트 후 입금 확인
BingX 잔고에 TRX가 들어오면 TRX/USDT에서 USDT로 교환합니다.
업비트 원화→TRX→BingX TRX→BingX USDT

02 · 빗썸 → Bitget

빗썸을 이용한다면 같은 원리로 TRX를 전송합니다. 반드시 네트워크를 일치시켜야 합니다.

1
빗썸에 원화 입금
입출금 → 원화 → 입금에서 본인 명의 계좌를 사용합니다.
2
TRX 구매
TRX/KRW 마켓에서 원하는 금액만큼 매수합니다.
3
Bitget TRX 입금주소 확인
Assets → Deposit → TRX에서 Address와 Network를 확인합니다.
4
주소와 네트워크 확인
빗썸 출금 화면에서 받는 거래소 Bitget을 선택하고 동일한 네트워크로 입력합니다.
5
본인확인·트래블룰 진행
출금 화면의 거래소 선택, 수취인 정보, 추가 보안인증을 완료합니다.
6
입금 확인 후 USDT 교환
Bitget TRX 잔고를 확인한 뒤 TRX/USDT에서 매도합니다.
빗썸 원화→TRX→Bitget TRX→Bitget USDT

03 · BingX API 키 받기

API는 자동매매 프로그램이 거래소 계좌를 조회하거나 주문할 때 사용하는 연결 열쇠입니다. 키 자체를 웹페이지·채팅·GitHub에 올리면 안 됩니다.

1
BingX 로그인 → API 관리
프로필 또는 계정 보안 메뉴에서 API Management를 엽니다.
2
Create API Key
새 API 키를 만들고 용도를 알아보기 쉬운 이름으로 지정합니다.
3
권한 최소 설정
잔고·포지션 조회와 필요한 거래 권한만 켭니다. 출금 권한은 절대 켜지 않습니다.
4
IP 제한 설정
가능하면 자동매매 서버의 고정 IP만 허용합니다. 전체 IP 허용은 피합니다.
5
Secret Key 즉시 보관
생성 직후 한 번만 표시될 수 있으므로 비밀번호 관리자 또는 서버 비밀변수에 저장합니다.
6
연결 테스트
키와 시크릿을 코드에 직접 쓰지 말고 환경변수로 등록한 뒤, 먼저 잔고 조회만 테스트합니다.
✓ 권장읽기·잔고·포지션 조회
필요한 경우에만 선물 거래
✕ 금지출금 권한
공개 저장소·스크린샷·메신저 공유

04 · 출금 전 최종 체크

코인 종류가 양쪽 모두 TRX인가
네트워크가 양쪽 모두 TRON(TRX)인가
Address를 앞·뒤로 비교했는가
추가 메모 입력란이 표시되는지 확인했는가
본인 명의 계정으로 보내는가
처음이면 소액 테스트를 했는가
해외거래소 입금 완료를 확인했는가
API 출금 권한이 꺼져 있는가
안전 원칙: 계정 연결 성공은 주문 실행 완료와 다릅니다. 거래소 정책과 지원 네트워크를 출금 당일 다시 확인하세요.
이 페이지는 이용 절차 안내용이며 투자 수익이나 거래 성공을 보장하지 않습니다.
