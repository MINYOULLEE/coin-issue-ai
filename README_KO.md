## 가장 쉬운 Supabase 연결

Windows에서 `SETUP_SUPABASE_WINDOWS.bat`을 실행하고 Supabase의 `sb_secret_...` 키를 붙여넣으면 `.env`가 자동 생성되고 수집기가 시작됩니다. 비밀키는 이 PC의 `.env`에만 저장되며 GitHub에는 업로드되지 않습니다.

공식기관, 주요 코인 매체, 거래소 공지의 새 게시물을 15초마다 확인합니다. 코인과 직접 관련된 내용만 통과시키고 BTC·ETH·XRP·SOL·BNB 등으로 자동 분류합니다. 실시간 가격과 24시간 등락률을 함께 확인해 뉴스의 예상 방향과 실제 시장 반응을 구분합니다.

## Windows 실행

1. ZIP 압축을 풉니다.
2. `START_WINDOWS.bat`을 더블클릭합니다.
3. 브라우저에서 `http://127.0.0.1:8765`가 열립니다.

### 바탕화면 바로가기

압축을 푼 뒤 `CREATE_DESKTOP_SHORTCUT.bat`을 한 번만 실행하세요. 바탕화면에 `Coin Issue AI` 아이콘이 생성되며, 다음부터 해당 아이콘을 더블클릭하면 프로그램과 대시보드가 바로 열립니다. 압축을 푼 폴더를 옮기면 바로가기를 다시 생성해야 합니다.

이전 버전의 바로가기가 있어도 이 파일을 실행하면 현재 v6 폴더 경로로 교체됩니다. 정상 설치 여부는 화면 왼쪽 위의 `Coin Issue AI v6` 표시로 확인하세요.

Python 3.10 이상이 필요하며 외부 패키지는 필요하지 않습니다.

## AI 요약과 텔레그램 설정

첫 실행 후 생긴 `.env` 파일을 메모장으로 열어 값을 넣습니다.

```env
OPENAI_API_KEY=여기에_API_키
OPENAI_MODEL=gpt-5-mini
TELEGRAM_BOT_TOKEN=봇_토큰
TELEGRAM_CHAT_ID=채팅_ID
```

키가 없을 때도 키워드 기반 중요도·방향 판정과 대시보드는 작동합니다. 키가 있으면 새 이슈를 한국어로 요약합니다.

## 즉시성 설계

- 각 피드를 병렬 감시하며 기본 주기는 15초입니다.
- 최초 실행 때 과거 글을 알림으로 쏟지 않고 기준선만 저장합니다.
- 다음 실행부터 새 항목만 즉시 판정합니다.
- 공식 출처는 중요도 점수가 더 높습니다.
- 동일 제목/링크는 자동 제거됩니다.
- 실패한 출처는 화면의 `출처 상태`에서 확인됩니다.
- Binance·Coinbase·Kraken·OKX·Bybit 공지를 별도로 분류합니다.
- Binance 공개 시세 API로 BTC·ETH·XRP·SOL·BNB 가격을 10초마다 갱신합니다.
- `악재지만 가격 상승`, `호재지만 가격 하락`처럼 시장이 뉴스를 받아들이는 상태를 별도로 표시합니다.
- 현재 기준 24시간을 넘긴 뉴스는 수집하지 않으며, 저장된 오래된 항목도 실행 시 삭제합니다.
- B급(45점) 미만의 일반 기사와 반복 요약은 화면에서 제외합니다.
- 거래소 광고·이벤트·듀얼투자·일반 기능 안내는 제외하고 상장·상폐·입출금 중단·보안·규제 등 투자 영향 공지만 남깁니다.
- 각 이슈에는 투자자 관점의 중요 이유, 확인 행동, 예상 영향 시간을 표시합니다.

## 추천·예측 탭

- BTC·ETH·XRP·SOL·BNB의 1시간봉 500개를 분석합니다.
- 24시간 거래대금, 최근 24시간/직전 24시간 거래량 비율, RSI, 변동성, 24시간·3일·7일 모멘텀을 계산합니다.
- 최근 24시간 뉴스의 등급·방향·신뢰도를 코인별 뉴스 점수로 반영합니다.
- 24시간 및 1주 예상 중심가격과 변동성 기반 상·하단 범위를 표시합니다.
- `신뢰도 %` 대신 모든 코인을 동일한 100점 만점으로 평가합니다.
- 종합점수는 추세 일치 25점, 거래량 확인 20점, 뉴스 뒷받침 20점, 위험 건전성 20점, 데이터 품질 15점으로 구성됩니다.
- 100점은 100% 적중을 의미하지 않고 현재 확인 가능한 조건이 모두 뒷받침되는 최고 등급을 뜻합니다.
- 종합점수가 60점 미만이면 방향 예측이 있더라도 추천을 보류합니다.
- 과열·과매도, 지나친 거래량 급증, 높은 변동성, 관련 뉴스 부족은 예측 신뢰도를 감점합니다.

예측은 과거 가격·거래량과 현재 뉴스로 계산한 확률적 추정이며 확정 가격이나 수익 보장이 아닙니다. 갑작스러운 정책 발표·해킹·대규모 청산은 모델 범위를 벗어날 수 있습니다.

## 핫이슈 탭

- CFTC·SEC의 예정된 연설·회의·청문회와 FOMC 공식 일정을 미리 표시합니다.
- CLARITY 법안, 미국 암호화폐 정책, ETF 기관 자금, 대형 해킹처럼 최근 24시간에 반복 등장하는 핵심 테마를 묶습니다.
- 일정·테마별 중요 이유, 예상 성격, 다음 확인 지점, 관련 자산을 제공합니다.
- 주요 코인의 평균 가격 변화와 거래량 증가가 함께 나타나는지 확인해 `선행 반영 가능성`을 표시합니다.
- 가격 상승의 단독 원인을 특정 법안이나 연설로 확정하지 않고 복수 근거가 시간 순서상 일치할 때만 가능성으로 표현합니다.

`config.json`에서 `poll_seconds`를 5초까지 줄일 수 있으나, 너무 짧으면 기관 서버가 요청을 제한할 수 있습니다.

## 중요한 현실적 한계

RSS는 공식 게시와 거의 동시에 잡지만, 영상 속 연설 음성을 직접 듣는 기능은 이 MVP에 포함되지 않습니다. 연설 중 10~30초 단위 음성 분석은 YouTube 실시간 자막 또는 유료 속보/전사 API 연결이 필요합니다. 이 버전은 그 기능을 다음 단계에서 연결할 수 있도록 소스 구조를 분리했습니다.

투자 판단을 보조하는 도구이며 자동매매나 수익을 보장하지 않습니다.
